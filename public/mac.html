알아두세요

Windows 버전과 어떤 기능이 같나요?

기본 곰인형, PNG 교체, 키링 3개와 개별 설정, 체인 5종, 아크릴 효과, 연결 지점, 흔들림·감쇠, 미리보기와 설정 저장을 제공합니다. 시스템 트레이 대신 Mac 메뉴 막대에서 관리합니다. 두 운영체제의 설정을 자동 동기화하지는 않습니다.

무엇을 검증했나요?

Apple Silicon과 Intel의 macOS 빌드 서버에서 같은 Universal 앱을 실행하고, 물리·설정 저장·이미지 교체·아크릴과 체인 렌더링·오버레이 속성을 확인했습니다. 실제 사용자 Mac의 클릭·드래그, 외부 모니터, ProMotion, Spaces·전체 화면 동작은 추가 확인이 필요합니다.

별도 권한을 허용해야 하나요?

전역 마우스 위치를 읽고 클릭을 통과시키는 투명 패널로 표시합니다. 화면 녹화, 손쉬운 사용 제어, 입력 감시 권한을 요청하지 않으며 배경 화면을 캡처하지 않습니다.

설정과 이미지는 어디에 보관되나요?

Mac의 ~/Library/Application Support/DesktopKeyring 폴더에 저장합니다. PNG를 복사해 사용하므로 원본을 이동해도 보관한 이미지를 불러올 수 있습니다. 자동 업데이트는 포함하지 않습니다.
