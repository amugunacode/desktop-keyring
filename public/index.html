GOOD TO KNOW

궁금한 점이 있나요?

인터넷 창 위에서도 보이나요?

바탕화면과 일반 창 모드 앱 위에 표시됩니다. 키링은 클릭·드래그·스크롤을 통과시키고 작업 중인 창의 포커스를 가져오지 않습니다. 독점 전체 화면 게임이나 보안 화면에서는 표시가 제한될 수 있습니다.

어떻게 숨기거나 종료하나요?

작업표시줄 오른쪽 시스템 트레이의 곰인형 아이콘을 오른쪽 클릭하세요. ‘전체 키링 표시’로 숨기거나 ‘종료’를 선택할 수 있어요. 아이콘이 안 보이면 숨겨진 아이콘 영역(∧)을 열어주세요.

내 이미지와 설정은 어디에 저장되나요?

PC의 사용자 앱 데이터 폴더(%LOCALAPPDATA%\CursorCharm)에 저장됩니다. 프로그램은 불러온 PNG를 해당 폴더에 복사해 사용하며, 다음 실행 때 저장한 설정을 불러옵니다.

Windows에서 실행 경고가 나와요.

현재 배포 파일에는 코드 서명이 없어 Windows에서 게시자 확인 경고가 나타날 수 있습니다. 이 페이지가 연결하는 GitHub Releases에서 받은 파일인지 먼저 확인하세요. 회사·학교 PC의 실행 정책에 따라 사용이 제한될 수 있습니다.

업데이트는 어떻게 하나요?

기존 프로그램을 트레이에서 종료한 다음, 이 페이지에서 새 버전을 받아 압축을 풀고 실행하세요. 기존 사용자 설정은 유지됩니다. 자동 업데이트 기능은 아직 제공하지 않습니다.
